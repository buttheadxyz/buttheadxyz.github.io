# Wordplode – Support & Information

Welcome! This repository hosts the **official support site** for **Wordplode**, a mobile word puzzle game where **classic wordplay meets fast-paced block strategy**.

Think **word-building meets falling tiles** — easy to learn, challenging to master.

---

## 🎮 About the Game

Wordplode blends the best parts of traditional word games and tile-stacking puzzles into a fresh, modern experience.

### Features:
- 🧩 Word-based puzzle gameplay
- 🔤 Build words from falling letter tiles
- 📱 Designed for mobile devices
